# MediaServe · COP Akweteyman Worship Center (AKWC) Media Ministry

**MediaServe** is a specialized, enterprise-grade broadcast and volunteer management system built for the COP Akweteyman Worship Center (AKWC) Media Ministry. It streamlines service rostering, automated WhatsApp volunteer dispatches, live attendance confirmation tracking, role-based leadership oversight, and secure multi-device access.

## 🚀 Core Workflows & Features
* **End-to-End Workflow:** Create Service → Assign Roles → Remind Volunteers → Confirm Attendance → Monitor Live Roster.
* **Smart WhatsApp Dispatches:** Generates pre-formatted WhatsApp notification links with secure one-tap confirmation links for crew members.
* **Role-Based Access Control (RBAC):**
  * **Super Admin:** Full administrative control over system data, member security credentials, and role privileges.
  * **Media Leadership:** Manage services, team rosters, attendance monitoring, and post announcements.
  * **Media Patron:** Read-only overview of ministry rosters and service metrics with announcement publishing capabilities.
  * **Team Members:** Secure authentication, mobile dashboard viewing, and direct duty confirmation or excuse submissions.
* **Advanced Session Security:** Automated inactivity timeout warnings and session protection protocols.
* **Cross-Platform Mobile Ready:** Fully responsive layout optimization with PWA home screen installation support for Android and iOS devices.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
* **Database & Realtime Sync:** Supabase (PostgreSQL)
* **Deployment & Distribution:** Progressive Web App (PWA) / Service Workers
